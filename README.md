# theprepared-PFM (Personal Financial Management)

개인 자산 관리 및 가계부 애플리케이션 서비스입니다.

## 주요 기능
- **거래 입력 및 조회**: 일별 거래 내역 입력, 차변/대변 복식부기 계정 관리.
- **거래 프리셋 (고정지출/자주입력)**: 월별 고정지출 항목(월세, 통신비 등) 및 자주 사용하는 거래 패턴을 등록하여 간편 입력.
- **자산 현황 및 통계**: 계정별 잔고, 자산/부채/순자산/수익/비용 통계 및 예산 관리 기능.

## 거래 프리셋 (고정지출) 관리
- 설정(`account:settings`) 페이지의 **거래 프리셋 관리** 섹션에서 새로운 고정지출 및 자주입력 프리셋을 등록/수정/삭제할 수 있습니다.
- 고정지출 등록 시 프리셋 이름, 아이템, 금액, 고정 일자(1~31), 차변 계정(+), 대변 계정(-)을 지정합니다.
